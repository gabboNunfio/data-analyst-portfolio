# Calculator

A modular calculator developed in Python as part of my Data Analyst Portfolio.

The project demonstrates fundamental Python programming, error handling, testing with Pytest, project organization and Git-based version control.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulo
- Power
- Division-by-zero validation
- Modulo-by-zero validation
- Automated tests with Pytest

## Technologies

- Python 3.13
- Pytest
- Git
- GitHub
